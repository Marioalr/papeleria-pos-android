# Papelería POS para Android

La app Android de [Papelería POS](https://github.com/Marioalr/papeleria-pos): los celulares de la tienda escanean con
la cámara lo que hoy pasa por el lector de la caja.

> **Estado: plan de la fase 1, el escáner.** Leer EAN-13, UPC-A, UPC-E, EAN-8, ITF-14, Code 128 y QR con la cámara,
> guiar al personal para que el código se lea (muévete, acércate, aléjate, mantén firme, luz, reflejo) y confirmar cada
> lectura con bip, vibración y verde, con el máximo rendimiento medido. Todavía sin conexión al POS. Las decisiones
> están en el [plan](docs/plan.md).
